This is Accessory Forge, a roblox studio plugin to instantly convert any **MODEL** into an accessory!
You only have to input your desired rig type, then accessory type, select the part and press convert.
This was written in TypeScript using the VisualCode editor and then compiled over to LUAU and tested to make sure everything was working.
